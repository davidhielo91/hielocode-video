# Créditos y herramientas externas

Estas instrucciones y el script de inspección se redactaron para este repositorio. Los proyectos de abajo se enlazan para que cada usuario obtenga el software y la documentación de sus autores. Sus licencias y términos se aplican a sus respectivos componentes.

| Proyecto | Uso contemplado | Fuente del autor |
| --- | --- | --- |
| FFmpeg y FFprobe | Procesamiento y análisis local de medios. Licencia LGPL o GPL según la compilación. | [Información de licencia](https://ffmpeg.org/legal.html) |
| HeyGen HyperFrames | Motion graphics y composición de video. El repositorio declara Apache-2.0. | [Repositorio y licencia](https://github.com/heygen-com/hyperframes) |
| Remotion | Composición React y, cuando el proyecto lo admite, entrega OTIO. El motor tiene su propia licencia. | [Licencia del motor](https://www.remotion.dev/pricing) |
| ComfyUI y Comfy CLI | Generación por flujos de trabajo. La CLI declara GPL-3.0. Los modelos pueden tener términos distintos. | [Comfy CLI](https://github.com/Comfy-Org/comfy-cli) |
| OpenTimelineIO | Formato de intercambio de líneas de tiempo. | [Proyecto y licencia](https://github.com/AcademySoftwareFoundation/OpenTimelineIO) |
| fal.ai y HeyGen | Servicios de generación opcionales. | [fal.ai](https://fal.ai/models), [HeyGen](https://docs.heygen.com/) |
